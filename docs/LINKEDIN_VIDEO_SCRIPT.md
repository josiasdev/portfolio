# 🎥 Roteiro de Vídeo & Guia de Publicação para LinkedIn

Este documento contém o roteiro completo de gravação de vídeo, texto para teleprompter e a publicação (copy) pronta para o LinkedIn referente ao novo portfólio.

## 📱 Texto para Teleprompter (Fala Contínua)

Fala pessoal! Hoje estou muito animado em compartilhar com vocês a versão final do meu novo portfólio profissional como Desenvolvedor Blockchain e Engenheiro de Protocolos.

Decidi construir uma experiência focada na engenharia e no minimalismo — uma estética inspirada em grandes referências da comunidade global de software.

Aqui reuni minha jornada em Engenharia de Software na UFC Quixadá, minha atuação como Desenvolvedor Residente em Web 3.0 no iRede, além das minhas especialidades em Smart Contracts com Solidity no EVM, Rust e Soroban na rede Stellar, e microsserviços robustos em Java e Spring Boot.

Um dos recursos que mais gostei de desenvolver foi a internacionalização completa. O site suporta Português, Inglês e Espanhol. E o mais legal: ao trocar o idioma, o botão de download adapta dinamicamente o PDF do meu currículo para a versão selecionada.

A navegação conta com um rastreamento ativo pelas 9 seções do site, destacando meus principais projetos Web3 com métricas em tempo real do GitHub, conquistas em hackathons globais como a Stellar Network e UNICEF, além de certificações técnicas verificáveis.

Também temos um alternador de tema global entre os modos Escuro e Claro, e uma experiência mobile responsiva de altíssima performance.

A aplicação foi desenvolvida utilizando React 18, Vite 5, TypeScript 5, Tailwind CSS e Serverless Functions para envio de mensagens.

O link do portfólio e o código-fonte no GitHub estão aqui na publicação. Adoraria receber o feedback de vocês e me coloco à disposição para novas oportunidades e conexões em Web3 e Backend! Um grande abraço!
